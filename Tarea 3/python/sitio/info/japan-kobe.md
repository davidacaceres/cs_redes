<h3>Sobre la Ciudad: Kōbe</h3>
<p>
Kōbe  es una ciudad de Japón. Tiene una población estimada, a inicios de agosto de 2022, de 1 512 033 habitantes.
</p>
<h3>Sobre la Red de Metro: Metro Municipal de Kobe</h3>
<p>
El Metro de Kobe  es el sistema de metro local de Kobe. El sistema tiene dos líneas.
</p>
